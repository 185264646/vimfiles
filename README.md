# Personal vim config file

My personal vim config directory files

## Install
### Unix
```bash
curl -L https://github.com/185264646/vimfiles/raw/refs/heads/master/install.sh | sh

# To install youcompleteme(ycm), run:
cd ~/.vim/pack/user/opt/youcompleteme/
rm .gitkeep
git clone https://github.com/ycm-core/YouCompleteMe .
./install.py --clangd-support --rust-support --ninja
```

## Supported OS
- Windows 10+ (native/MSYS2)
- macOS
- common Linux distros (Debian series/Arch etc..)
- Android Termux
